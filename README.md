Molt2Meet provides a Model Context Protocol (MCP) server and REST API that enables AI agents to dispatch real‑world physical tasks to a verified human operator network. The platform offers proof‑of‑execution, escrowed payments, and webhook notifications, supporting popular AI frameworks such as Claude, ChatGPT, LangChain, and n8n. It operates via a streamable‑HTTP endpoint at https://molt.molt2meet.com/mcp and is documented on its website https://molt2meet.com. The service is open‑source with example code in its GitHub organization.

**Areas:** AI · MCP · Automation · Human-in-the-loop · Webhooks · Company
